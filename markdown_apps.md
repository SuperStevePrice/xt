## Viewing the Documentation

To ensure that you can correctly view the images included in this documentation, you can use one of the following Markdown editors:

1. **Typora** - A cross-platform Markdown editor with real-time preview and excellent image support.  
   OS: Linux, MacOS, Windows

- [Typora Website](https://typora.io/)

2. **Visual Studio Code** - A highly customizable code editor with Markdown extensions such as "Markdown All in One" and "Markdown Preview Enhanced" for image display.  
   OS: Linux, MacOS, Windows

- [Visual Studio Code Website](https://code.visualstudio.com/)

3. **Remarkable** - A simple and lightweight Markdown editor that supports image embedding.  
   OS: Linux

- [Remarkable GitHub Repository](https://remarkableapp.github.io/linux.html)

4. **Ghostwriter** - A distraction-free writing environment for Markdown with image support.
   OS: Linux, Windows
   
- [Ghostwriter GitHub Repository](https://github.com/wereturtle/ghostwriter)

5. **Haroopad** - A Markdown editor with live preview and image support.

- [Haroopad Website](http://pad.haroopress.com/)
  OS: Linux, MacOS, Windows
  
Choose the one that best suits your platform and preferences. These editors provide a smooth experience for viewing and editing Markdown documents with embedded images.

If you encounter any issues with image display, please make sure the image files are in the same directory as this documentation, or refer to the installation and usage instructions provided by the respective Markdown editor.
